Bachelor Saviour V2

The AI-Powered Magic Cookbook

A Local-First Web Application

The Problem

Cooking is intimidating for beginners. You open your fridge, see randomly mismatched ingredients, and have no idea what to make. Searching for recipes takes too long, and most recipes require ingredients you don't have.

The Solution

  • Input what you have: Tell the app your ingredients.
  • Set preferences: Specify cuisines or dietary filters.
  • AI Magic: An advanced LLM instantly constructs a step-by-step recipe.
  • Beautiful UX: Read the generated recipe in a stunning, interactive 3D book interface.

Technical Architecture V2 Upgrade

  • Migrated from traditional Backend servers to 100% Client-Side.
  • Vite & Vanilla JS: Lightning fast load times.
  • Groq API: Integrated directly in the browser via native `fetch`. LLaMA-based generation taking milliseconds.
  • Bring-Your-Own-Key (BYOK): API keys are stored in `localStorage`, meaning zero hosting costs for the developer.

Security & Performance

  • Cross-Site Scripting (XSS) Prevention: AI Markdown is rigorously scrubbed by DOMPurify before being injected into the DOM.
  • Smart Pagination: Complex logic dynamically chunks the recipe into 3-step pages, allowing for a perfectly sized 3D reading experience without layout breakage.
  • Edge-Ready: Can be deployed on Vercel, Netlify, or GitHub Pages instantly for free.
