# Security Policy — Bachelor Savior V2

## Architecture Overview

Bachelor Savior V2 transitioned from a central-backend model to a **fully local-first, standalone web application**. 

- ✅ **No Backend:** There is no database, no caching server, and no internal API proxy.
- ✅ **Bring-Your-Own-Key (BYOK):** Users provide their own Groq API key to power AI generations.
- ✅ **100% Client-Side:** All logic, Markdown parsing, and state management happen locally in the user's browser.

---

## Secret Storage & API Keys

The application does **not** host, process, or store API keys remotely. 

| Where | What is stored |
|---|---|
| `localStorage.bs_v2_groq_key` | The user's Groq API key (stays on device) |
| `localStorage.bs_saved_recipes` | The user's saved recipes |
| Network requests | Direct from browser to `api.groq.com/openai/v1/chat/completions` |
| Application Server | None (Only static files HTML/CSS/JS are served) |

**User Responsibility:** Because the key is stored in browser `localStorage`, anyone with physical access to your unlocked device/browser, or malicious browser extensions, could theoretically access the key. Users are responsible for managing the permissions and scope of their Groq API keys via the Groq Console. 

---

## XSS (Cross-Site Scripting) Prevention

Because Bachelor Savior renders Markdown generated by an AI LLM, there is an inherent risk of HTML injection (XSS).

To prevent this, the application natively implements **DOMPurify**.
All generated AI text is processed as follows:
1. Received from Groq API as Markdown string.
2. Parsed by `marked.js` into raw HTML.
3. Passed through `DOMPurify.sanitize(raw)` which strips all `<script>`, `<iframe>`, `onload=`, and inline JavaScript handlers.
4. Finally injected into the DOM (`innerHTML`).

---

## Content Security Policy (CSP)

When hosting this static site (e.g., Vercel, Netlify, or GitHub Pages), ensure you enforce a strict CSP:
- Scripts: Only allow `self` and pinned CDNs (cdnjs/jsdelivr).
- Connections: Allow `https://api.groq.com` for LLM traffic.
- Frames: Enforce `frame-ancestors 'none'` to block malicious clickjacking/embedding.

## Responsible Disclosure

This is an open-source, local-first hobby project. If you discover a security vulnerability (such as an XSS bypass within our implementation), please open a [GitHub Issue](https://github.com/mikey2008/Bachelor-Savior/issues) marked `[SECURITY]` or contact the maintainer directly via GitHub.
